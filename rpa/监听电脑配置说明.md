# 换图监听电脑配置

## 工作流程

1. 测图看板服务器收到换图请求并生成 Excel。
2. 监听电脑定时请求服务器的待处理任务接口。
3. 监听电脑领取任务后，将 Excel 下载到 `rpa/received_excel/`。
4. 监听电脑启动换图 RPA，并持续把进度回传服务器。

## 监听电脑设置

打开 `start_listener.bat`，将示例中的服务器地址改为实际的测图看板服务器地址：

```bat
set SWAP_SERVER_URL=http://服务器IP:8766
```

也可以在启动前设置环境变量：

```bat
set SWAP_SERVER_URL=http://192.168.1.10:8766
set SWAP_LISTENER_ID=换图电脑01
start_listener.bat
```

监听端默认每 5 秒检查一次任务，每次只执行一个换图任务。

## Excel 内容

- `主图数据`：店铺名称、商品ID、图片地址、商品编码、操作人员。
- `替换数据`：店铺名称、商品ID、图片地址、商品编码、操作人员。
- `操作人员` 当前固定留空。
